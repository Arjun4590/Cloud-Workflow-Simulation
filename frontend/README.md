# CloudLens Frontend

Interactive Cloud Execution Visualizer and Workflow Simulator built with React 19, TypeScript, Vite, Tailwind CSS, and `@xyflow/react`.

For complete system architecture, algorithm descriptions, and simulation documentation, see the [Root README](../README.md).

## Available Scripts

In the `frontend` directory:

- `npm run dev`: Starts Vite local development server
- `npm test`: Runs Vitest test suite once across all unit and engine tests
- `npm run test:watch`: Runs Vitest in interactive watch mode
- `npm run lint`: Runs Oxlint static code analyzer
- `npm run build`: Type-checks with TypeScript (`tsc -b`) and bundles for production (`vite build`)
- `npm run preview`: Previews the production build locally
